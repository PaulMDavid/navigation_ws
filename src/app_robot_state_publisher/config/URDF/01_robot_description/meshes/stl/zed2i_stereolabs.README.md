# zed2i_stereolabs.stl

Official ZED2i model from Stereolabs' `zed-ros2-description` (`meshes/zed2i.stl`,
master, fetched 2026-11-19), Apache License 2.0 (`zed2i_stereolabs.LICENSE`), unmodified.

Metres, origin = the wrapper's `<camera>_camera_center` (x forward, y left, z up):
x −0.0180..0.0251, y ±0.0876, z −0.0149..0.0153.

`ZED2i.stl` next to it is the older model from the sim (millimetres, axes not aligned
to the ROS camera frames); kept, unused.
